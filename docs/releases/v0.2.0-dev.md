# v0.2.0-dev Release Notes

v0.2.0-dev 已稳定化为 v0.2.0-rc1。rc1 发布说明见 `docs/releases/v0.2.0-rc1.md`，发布检查清单见 `docs/releases/release_checklist_v0.2.0-rc1.md`。

## 新增功能

- 新增案件工作区，可创建、选择和删除案件。
- 单次复核和批量复核可关联 `case_id`。
- 新增历史复核记录，可查看详情、继续填写人工复核记录并重新导出报告。
- 新增批量复核入口，多份 DOCX/PDF 可分别生成独立 review_id，单个失败不影响其他文件。
- 新增案件级复核包，包含案件汇总 Excel、案件 HTML 报告和单份文书复核包。
- 新增案件内字段差异提示，对同一案件下多份文书的基础字段做轻量对比。
- 新增 `case_08_case_workspace_batch` 演示数据。

## 数据库变化

- 新增 `case_workspaces` 表，保存案件工作区信息。
- 新增 `case_documents` 表，保存案件下文书元数据。
- `review_runs` 增加 `case_id`、`document_id`、`file_name`、`mode_label`、高中低风险数量、外部复核字段数量和外部复核字段 JSON。
- `manual_review_records` 继续按 `review_id` 关联，可通过 review_run 间接关联案件。

## 向后兼容说明

- `init_db()` 会自动创建新表，并用可重复执行的 `ALTER TABLE` 为旧 `review_runs` 补充新列。
- 旧的 `save_review_run(findings)` 调用仍然可用。
- 未选择案件时仍然支持临时复核模式。

## 隐私与安全

- 不保存完整上传文书正文。
- 仅保存文件元数据、复核结果、待外部复核字段、人工复核记录和必要统计信息。
- 案件内字段差异提示仅表示不同文书之间字段不一致，需人工判断是否属于正常版本差异，不构成法律结论。

## 已知限制

- 案件内差异提示为字段级轻量对比，不做 Word 修订痕迹或语义 diff。
- 批量复核仍使用本机串行处理，超大文件或大量文件可能耗时较长。
- 历史记录不重新打开原文书正文，只基于已保存的 findings、外部字段和人工记录展示。

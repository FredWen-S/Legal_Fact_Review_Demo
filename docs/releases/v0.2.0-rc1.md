# v0.2.0-rc1 Release Notes

## 新增功能

- 案件工作区：支持创建、选择、查看和删除案件。
- 历史复核记录：支持查看历史 review、继续填写人工复核记录并重新导出报告。
- 批量复核：支持一次上传多份 DOCX/PDF；单个文件失败不影响其他文件。
- 案件级复核包：导出案件复核汇总 Excel、案件 HTML 报告和单份文书复核包。
- 案件内字段差异提示：对同一案件下多份文书的基础字段做轻量对比。
- 测试数据：新增 Case 08，用于案件工作区和批量复核演示。

## 保留能力

- 单文书字段抽取模式。
- 完整复核模式。
- 人工复核工作流。
- Excel / HTML / Word / ZIP 报告导出。
- Windows portable 本地启动。
- SQLite 本地留痕。
- 可选 OCR。

## 数据库变化

- 新增 `case_workspaces` 表。
- 新增 `case_documents` 表。
- `review_runs` 增加 `case_id`、`document_id`、`file_name`、`mode_label`、高中低风险数量、外部字段数量和 `external_fields_json`。
- `init_db()` 会自动迁移旧 v0.1 数据库，并且可重复执行。
- 旧 `save_review_run(findings)` 调用保持兼容。

## Windows Portable

- `app/__init__.py` 已保留。
- `start.bat` 设置 `PYTHONPATH=%CD%`，避免 `ModuleNotFoundError: No module named 'app'`。
- 启动 Streamlit 使用 `.venv\Scripts\python.exe -m streamlit run app\main.py`。
- `start.bat` 保持 ASCII、CRLF 和日志输出到 `logs/startup.log`。
- Python 支持 3.10-3.12；v0.2.0-rc1 推荐 Python 3.12。
- 如果包含 `wheelhouse/`，wheelhouse 必须与目标 Python 版本匹配。cp312 wheelhouse 必须使用 Python 3.12；cp311 wheelhouse 必须使用 Python 3.11。
- preflight 会识别 wheelhouse Python tag，不匹配时给出清晰提示并停止。

## 隐私与安全

- 不接入外部 API。
- 默认本地运行，不访问第三方网站或外部数据库。
- 不保存完整上传文书正文。
- 不自动修改 Word 原文。
- 所有风险提示仍然只表达为“建议人工复核”。
- 案件内字段差异提示仅表示不同文书之间字段不一致，需人工判断是否属于正常版本差异，不代表系统判断错误，不构成法律意见。

## 已知限制

- 案件内字段差异提示为字段级轻量对比，不做 Word diff 或语义判断。
- 批量复核为本地串行处理，大批量文件耗时取决于本机性能。
- 历史记录基于 SQLite 中保存的复核结果和人工记录展示，不重新打开原文书正文。

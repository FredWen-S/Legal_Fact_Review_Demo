# v0.3.0-dev Release Notes

v0.3.0-dev 已稳定化为 v0.3.0-rc1。rc1 发布说明见 `docs/releases/v0.3.0-rc1.md`，人工验收清单见 `docs/releases/release_checklist_v0.3.0-rc1.md`。

## 新增功能

- 新增 Word 复核提示版导出：`<原文件名>_复核提示版.docx`。
- 支持基于 findings、待外部复核字段和人工复核记录，在原 DOCX 副本中插入“【复核提示】”块。
- 文末新增“复核提示汇总”，包含高风险优先处理清单、未定位复核提示、待外部复核字段、人工复核记录和免责声明。
- 单份复核包可在当前会话有 DOCX 原文时包含 `复核提示版文书/`。

## 实现策略

- 当前采用稳定的提示块插入方案，而非强依赖 Word 原生 comments。
- 优先按 `document_value` 在段落和表格中定位。
- 找不到时按 `source_location` 中的段落序号定位。
- 仍无法定位时写入文末“未定位复核提示”。

## 隐私与安全

- 不覆盖原始 Word 文件。
- 不自动修改原文正文，只生成新的 DOCX 副本。
- 不接入外部 API，不上传文件。
- 不保存完整原文书正文到 SQLite。
- 提示版 Word 会包含原文内容，用户应按案件材料保密要求妥善保存。
- 所有提示仍表达为“建议人工复核”，不构成法律意见。

## 已知限制

- 仅支持 DOCX 原文书生成提示版。
- PDF 仍可导出 Word 摘要，但不生成原文提示版。
- 历史记录不保存原文书正文，因此历史详情不能重新生成原文提示版。
- 提示定位为启发式匹配，不保证每条提示都能插入原文准确位置。

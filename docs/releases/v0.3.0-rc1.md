# v0.3.0-rc1 Release Notes

## 版本信息

- 版本号：v0.3.0-rc1
- 发布类型：Release Candidate

## 新增功能

- 新增 Word 复核提示版导出：`<原文件名>_复核提示版.docx`。
- 在 DOCX 原文副本中插入“【复核提示】”块，并在文末生成“复核提示汇总”。
- 当前会话上传 DOCX 后导出的 ZIP 复核包可包含 `复核提示版文书/`。

## 与 Word 摘要的区别

- Word 复核摘要是独立摘要报告，不包含原文全文。
- Word 复核提示版基于用户当前上传的 DOCX 生成副本，包含原文内容，并在相关位置附近插入复核提示。

## 支持范围

- 仅支持 DOCX 原文提示版。
- PDF 可以继续导出 Word 复核摘要，但不生成原文复核提示版。
- 历史记录不保存原文正文，因此不能从历史记录重新生成原文提示版。

## 安全与合规

- 不覆盖原始 Word 文件。
- 不自动修改原文正文，只生成新的 DOCX 副本。
- 不保存完整原文书正文到 SQLite。
- 不接入外部 API，不上传文件。
- 不构成法律意见，最终判断由律师或相关人员完成。
- 所有提示仍表达为“建议人工复核”。
- 提示版 Word 包含原文内容，用户应按案件材料保密要求妥善保存。

## 测试结果

- `python -m pytest -q`：通过。
- `python scripts/acceptance_check.py`：通过。

## 已知限制

- 当前采用稳定提示块方案，不使用 Word 原生 comments。
- 定位为启发式匹配：优先文书值，其次段落序号；无法定位时进入文末汇总。
- 不支持 PDF 原文提示版。
- 历史记录只能重新导出摘要类报告，不能重新生成原文提示版。

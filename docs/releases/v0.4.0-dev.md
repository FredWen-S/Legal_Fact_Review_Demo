# v0.4.0-dev Release Notes

## 新增功能

- 新增规则配置中心。
- 支持风险类型启用/禁用。
- 支持 severity 映射配置。
- 支持占位符模式配置。
- 支持外部复核来源和建议动作配置。
- 新增文书类型模板：通用文书、民事起诉状、答辩状、仲裁申请书、合同审查、律师函、执行申请书。
- 新增字段词典管理和导入/导出。
- 字段词典 alias 会影响标签式字段抽取。
- 支持规则配置导入、导出、恢复默认和备份。
- 新增 `rule_config_history` 配置变更历史。
- review_run 记录 `config_version` 和 `document_profile`。
- 报告中展示规则配置版本和文书类型模板。
- 新增 Case 09 自定义规则测试数据。

## 安全与边界

- 不接入外部 API。
- 不上传文件。
- 不保存完整原文书正文。
- 不自动修改原文书。
- 不输出法律结论。
- 配置错误时回退默认配置，避免系统崩溃。
- 配置中心用于调整辅助复核规则，不代表系统能够自动完成法律判断。

## 已知限制

- v0.4.0-dev 主要产品化现有配置能力，不引入新模型。
- 文书类型模板 MVP 影响 MISSING_FIELD 的必填字段范围，暂不做复杂语义抽取。
- 字段词典 alias 管理已支持配置、导入/导出和标签式抽取；复杂正则在线编辑仍建议通过 YAML 管理。

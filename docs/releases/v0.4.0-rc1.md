# v0.4.0-rc1 Release Notes

## 版本信息

- 版本号：v0.4.0-rc1
- 发布类型：Release Candidate

## 新增功能

- 规则配置中心：支持风险类型开关、风险等级映射、占位符模式、外部复核来源和建议动作配置。
- 文书类型模板：支持通用文书、民事起诉状、答辩状、仲裁申请书、合同审查、律师函、执行申请书。
- 字段词典管理：支持字段 alias 配置，alias 会影响标签式字段抽取。
- 配置导入 / 导出 / 恢复默认：支持 YAML / JSON，导入前校验，失败时不覆盖旧配置。
- 配置历史：成功导入、保存或恢复默认会写入 `rule_config_history`。

## 数据库变更

- `review_runs` 新增 `config_version` 和 `document_profile`。
- 新增 `rule_config_history` 表。
- `init_db()` 支持旧库自动补列、建表并可重复执行，不删除旧 `review_runs` 或人工复核记录。
- SQLite 不保存完整上传文书正文。

## 报告与历史记录

- Excel 复核工作底稿、HTML 报告、Word 复核摘要和 ZIP 复核包展示当次 `config_version` 和 `document_profile`。
- 案件级复核包在文书复核汇总中展示配置版本和文书类型模板。
- 历史记录使用当次保存的配置版本和文书类型模板，不会被当前最新配置覆盖。

## 安全与边界

- 默认本地运行，不接入外部 API，不上传文件。
- 配置中心用于调整辅助复核规则，不代表系统能够自动完成法律判断。
- 所有建议动作必须表达为“建议人工复核”。
- 输出结果仅用于辅助人工复核，不构成法律意见。
- 不保存完整原文书正文；导出文件由用户按案件材料保密要求妥善保存。

## 已知限制

- 文书类型模板主要影响 `MISSING_FIELD` 的必填字段范围，不做复杂法律语义判断。
- 字段 alias 主要支持“标签：值”式抽取；复杂段落语义识别仍建议人工复核。
- 配置导入失败时保留旧配置；失败尝试不会写入覆盖性配置历史。
- OCR 仍为可选本地能力，扫描件识别质量取决于原始 PDF。

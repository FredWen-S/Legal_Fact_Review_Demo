# v0.5.0-dev Release Notes

## 新增能力

- 新增 Tauri 桌面壳骨架，目录位于 `desktop/`。
- 新增 `scripts/desktop_service.py`，用于启动、停止和查询本地 Streamlit 服务。
- 桌面壳提供启动状态、服务地址、PID、日志展示和 data / exports / logs 目录入口。
- 新增 `scripts/build_desktop_release.py`，用于生成桌面版开发交付目录。

## 架构

```text
Tauri Desktop Shell
  -> scripts/desktop_service.py
  -> Local Python Service
  -> Existing Streamlit App
```

桌面壳只是交付和用户体验增强，不重写核心 Python 复核引擎，不改变核心复核规则语义。

## 服务管理

- `logs/service.pid` 记录本项目服务进程。
- `stop` 只停止 pid 文件记录的进程，不按 `python.exe` 全局结束进程。
- `status` 输出 JSON，便于 Tauri 前端展示。
- `logs` 输出最近日志行。

## 兼容性

- 保留 `streamlit run app/main.py`。
- 保留 Windows portable `start.bat`。
- 保留 Docker 启动方式。
- Python 要求仍为 3.10-3.12，推荐 3.11 或 3.12。

## 安全与边界

- 不接入外部 API。
- 不上传文件。
- 不访问第三方网站或外部数据库。
- 不自动修改原文书。
- 不保存完整上传文书正文到 SQLite。
- 配置中心用于调整辅助复核规则，不代表系统能够自动完成法律判断。
- 输出结果仅用于辅助人工复核，不构成法律意见。

## 已知限制

- 当前为 v0.5.0-dev 桌面壳骨架，优先支持 dev 模式和服务管理脚本。
- 当前环境未强制完成 Tauri 安装包构建；需要本机具备 Node.js、Rust 和 WebView2。
- 桌面壳第一阶段打开本地 Streamlit 地址，不重写前端页面。

## 测试方式

```bash
python -m pytest -q

```

# v0.5.0-rc1 Release Notes

## 版本信息

- 版本号：v0.5.0-rc1
- 发布类型：Release Candidate

## 桌面壳能力

- 新增 Tauri v2 桌面壳，提供本地服务状态、启动、停止、打开复核界面、打开 data / exports / logs 目录和日志展示。
- 桌面壳调用 `scripts/desktop_service.py` 管理本地 Python / Streamlit 服务。
- 桌面壳启动服务时通过 `scripts/python_selector.py` 选择 Python，优先 `py -3.12`，拒绝 Python 3.13。
- 桌面服务日志、Rust command 返回和前端展示统一使用 UTF-8，中文错误不会静默失败或乱码。
- 桌面壳不承载业务复核逻辑，核心复核功能仍由 Python / Streamlit 提供。

## 服务管理方式

- `py -3.12 scripts/desktop_service.py status`
- `py -3.12 scripts/desktop_service.py start`
- `py -3.12 scripts/desktop_service.py stop`
- `py -3.12 scripts/desktop_service.py logs`

服务 pid 写入 `logs/service.pid`。`stop` 只处理该 pid，并检查其是否属于本项目启动的 Streamlit 服务，不按进程名结束其他 Python 进程。所有命令输出稳定 JSON；失败时包含 `ok: false` 和 `error`。

桌面服务启动选择顺序是 `py -3.12`、当前解释器如果是 3.12、`py -3.11`、当前解释器如果是 3.11、`py -3.10`、当前解释器如果是 3.10，最后才检查 `python`。如果只找到 Python 3.13，会返回中文错误：`未找到受支持的 Python 版本。请安装 Python 3.10-3.12，推荐 Python 3.12。`

## 样例数据保护

- `scripts/generate_test_files.py` 支持 `--output` 输出目录。
- `scripts/acceptance_check.py` 使用临时目录生成测试 case，不再覆盖 tracked 的 `app/sample_data/test_cases/`。
- 发布前仍建议确认 `app/sample_data/test_cases/` 没有非预期 modified；如需恢复可执行 `git restore -- app/sample_data/test_cases`。

## 版本关系

| 版本 | 启动方式 | 适合对象 |
| --- | --- | --- |
| Portable Streamlit 版 | 双击 `start.bat` | 稳定演示、低依赖交付 |
| Tauri 桌面壳版 | 打开桌面壳，再启动本地服务 | 更接近桌面应用体验 |
| 开发者模式 | `streamlit run app/main.py` / `npm run dev` | 开发调试 |

v0.5.0-rc1 桌面壳仍依赖本地 Python 服务，不是完全独立 exe。

## 安全与边界

- 不接入外部 API。
- 不上传文件。
- 不访问第三方网站或外部数据库。
- 不自动修改原文书。
- 不保存完整上传文书正文到 SQLite。
- 输出结果仅用于辅助人工复核，不构成法律意见。

## 已知限制

- 当前桌面壳第一阶段打开本地 Streamlit 服务，不重写前端业务界面。
- 需要本机具备 Python 3.10-3.12，推荐 Python 3.12；Python 3.13 当前不受支持。
- Tauri 安装包构建需要 Node.js、Rust 和 Windows WebView2 环境。

## 发布验证 Python 选择

v0.5.0-rc1 发布验证统一使用受支持 Python：优先 Python 3.12，其次 Python 3.11、Python 3.10。Python 3.13 仍不在支持范围内，preflight 不放开 3.13。

推荐验证命令：

```bash
py -3.12 -m pytest -q
py -3.12 scripts/acceptance_check.py
py -3.12 scripts/build_desktop_release.py
```

统一入口：

```bash
py -3.12 scripts/verify_release.py
```

如果系统默认 `python` 指向 Python 3.13，请不要直接运行 `python -m pytest`；发布脚本会通过 `scripts/python_selector.py` 选择 `py -3.12` / `py -3.11` / `py -3.10`，并拒绝 3.13。

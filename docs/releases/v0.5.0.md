# v0.5.0 Release Notes

## 版本信息

- 版本号：v0.5.0
- 发布类型：正式版

## 主要能力

- 本地运行律师文书基础信息与关键事实辅助复核。
- 支持完整复核模式、单文书字段抽取模式和案件批量复核模式。
- 支持人工复核记录、规则配置、复核历史、Word 提示版导出和案件级 ZIP 导出。
- 输出仅用于辅助人工复核，不构成法律意见，不替代律师判断。

## 桌面壳能力

- Tauri 桌面壳提供服务状态、启动、停止、打开复核界面、打开 data / exports / logs 目录和日志展示。
- 桌面壳仍依赖本地 Python / Streamlit 服务，核心复核逻辑仍在本地 Python 中运行。
- 所有按钮点击均有 loading、成功或失败反馈；服务未启动时打开复核界面会提示“请先启动服务”。
- Python 日志、Rust command 返回和前端展示统一使用 UTF-8，中文错误直接显示在桌面 UI。

## Portable 能力

- Windows portable 包提供 `start.bat` / `stop.bat`。
- 适合无需桌面壳的稳定演示和低依赖交付场景。

## 服务管理方式

建议显式使用 Python 3.12：

```bash
py -3.12 scripts/desktop_service.py status
py -3.12 scripts/desktop_service.py start
py -3.12 scripts/desktop_service.py stop
py -3.12 scripts/desktop_service.py logs
```

桌面启动链路会通过 `scripts/python_selector.py` 选择受支持 Python。选择顺序为 `py -3.12`、当前解释器如果是 3.12、`py -3.11`、当前解释器如果是 3.11、`py -3.10`、当前解释器如果是 3.10，最后才检查 `python`。

## Python 版本要求

- 推荐 Python 3.12。
- 支持 Python 3.10-3.12。
- 不支持 Python 3.13。
- 如果只找到 Python 3.13，会提示：`未找到受支持的 Python 版本。请安装 Python 3.10-3.12，推荐 Python 3.12。`

## 启动方式

| 版本 | 启动方式 | 适合对象 |
| --- | --- | --- |
| Portable Streamlit 版 | 双击 `start.bat` | 稳定演示、低依赖交付 |
| Tauri 桌面壳版 | 打开桌面壳，再启动本地服务 | 更接近桌面应用体验 |
| 开发者模式 | `streamlit run app/main.py` / `npm run dev` | 开发调试 |

## 隐私说明

- 工具不接入外部 API。
- 工具不上传文件。
- 工具不自动连接企查查、法院系统或内部数据库。
- 工具不自动修改原文书。
- SQLite 不保存完整上传文书正文。

## 已知限制

- 桌面壳不是完全独立 exe，仍需要本机具备受支持 Python。
- OCR 解析需要额外安装 `requirements-ocr.txt` 中的依赖。
- 复核结果仅基于用户上传文件和本地规则，必须由律师人工判断。

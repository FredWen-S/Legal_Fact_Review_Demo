# v0.6.0-dev Release Notes

后续 rc1 收口见 [v0.6.0-rc1.md](v0.6.0-rc1.md)。

## 版本信息

- 版本号：v0.6.0-dev
- 发布类型：开发版

## 目标

v0.6.0 的目标是 Windows 桌面端 installer / exe 打包。桌面入口仍为 Tauri Desktop Shell，Python / Streamlit 继续作为本地服务运行，不重写复核业务逻辑。

## Installer 能力

- 使用 Tauri v2 build 生成 Windows NSIS installer。
- 目标产物目录：`dist/LegalFactReview_v0.6.0_windows_installer/`。
- 目标安装器：`LegalFactReview_0.6.0_x64-setup.exe`。
- MSI 为可选产物：`LegalFactReview_0.6.0_x64.msi`。
- 构建脚本会生成 `SHA256.txt`。

## Python Runtime

installer 资源支持两种模式：

- 内置 Python：通过 `scripts/build_embedded_python.py --python-zip <python-3.12-embed-amd64.zip>` 或 `--python-dir <Python 3.12 runtime>` 准备 `desktop/src-tauri/resources/python/`。
- 不内置 Python：使用 `scripts/build_windows_installer.py --no-embedded-python`，运行时仍要求用户安装 Python 3.10-3.12，推荐 Python 3.12。

桌面服务启动顺序：

1. Tauri resource 内置 Python：`resources/python/python.exe`。
2. release 包相对路径下的 bundled Python：`python/python.exe`。
3. 系统 Python 3.12 / 3.11 / 3.10。

Python 3.13 不受支持。如果只找到 Python 3.13，会提示：`未找到受支持的 Python 版本。请安装 Python 3.10-3.12，推荐 Python 3.12。`

## 数据与隐私

- 用户数据仍保存在本地 `data/`、`exports/`、`logs/`。
- 不上传文件。
- 不接入外部 API。
- 不自动连接企查查、法院系统或内部数据库。
- 不保存完整原文书正文。
- 不自动修改原文书。
- 输出结果仅用于辅助人工复核，不构成法律意见。

## 与 Portable ZIP 的区别

| 版本 | 启动方式 | 适合对象 |
| --- | --- | --- |
| Portable Streamlit 版 | 双击 `start.bat` | 稳定演示、低依赖交付 |
| Tauri Installer 版 | 安装后从开始菜单或桌面入口启动 | 更接近普通桌面软件 |
| 开发者模式 | `streamlit run app/main.py` / `npm run dev` | 开发调试 |

## 构建命令

准备 app resources，不内置 Python：

```bash
python scripts/build_windows_installer.py --no-embedded-python
```

使用 Python embed zip 构建内置 Python installer：

```bash
python scripts/build_windows_installer.py --python-zip C:\path\python-3.12-embed-amd64.zip
```

使用已准备好的 Python 3.12 runtime 目录：

```bash
python scripts/build_windows_installer.py --python-dir C:\path\python312-runtime
```

## 已知限制

- 当前不自动联网下载 Python runtime；需要通过 `--python-zip` 或 `--python-dir` 提供 Python 3.12 runtime。
- 如果使用 `--no-embedded-python`，用户仍需本机安装 Python 3.10-3.12。
- installer 不改变核心复核规则和 Streamlit 业务页面。

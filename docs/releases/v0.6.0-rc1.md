# v0.6.0-rc1 Release Notes

## Installer Test Python Strategy

`scripts/build_windows_installer.py` now uses the current interpreter for its automated test stage when that interpreter is Python 3.10-3.12. This keeps the build on the Python environment that already has `pytest` and the project test dependencies installed. If the current interpreter is Python 3.13 or another unsupported version, the script falls back to `scripts/python_selector.py` and still only accepts Python 3.12 / 3.11 / 3.10.

If the selected test interpreter does not have `pytest`, the script fails early with:

```text
当前 Python 缺少 pytest。请先运行：<python> -m pip install -r requirements.txt 或使用 --skip-tests。
```

`--skip-tests` prints a warning and is intended only after manually running `pytest`, `acceptance_check`, and `verify_release`.

## 与 v0.5.0 desktop zip 的区别

| 版本 | 交付形式 | Python 要求 | 适合对象 |
| --- | --- | --- | --- |
| v0.5.0 desktop zip | 解压后进入 `desktop/` 运行开发命令 | 需要系统 Python 3.10-3.12 | 技术验收、桌面壳验证 |
| v0.6.0-rc1 no-python installer | NSIS 安装器 | 需要系统 Python 3.10-3.12，推荐 3.12 | 普通 Windows 安装体验验证 |
| v0.6.0-rc1 embedded-python installer | NSIS 安装器 + Python 3.12 runtime | 用户无需另装 Python | 目标正式交付路线 |

## Installer 构建

环境预检：

```bash
python scripts/check_installer_env.py
```

推荐构建环境使用 Node.js 20 LTS 或 22 LTS。Node 25 可尝试，但不是 v0.6.0-rc1 的正式推荐构建环境。

构建不内置 Python 的 installer：

```bash
python scripts/build_windows_installer.py --no-embedded-python
```

构建内置 Python 的 installer：

```bash
python scripts/build_windows_installer.py --python-zip C:\path\python-3.12-embed-amd64.zip
```

目标输出目录：

```text
dist/LegalFactReview_v0.6.0-rc1_windows_installer/
```

可能产物：

```text
LegalFactReview_v0.6.0-rc1_windows_installer_no_python.exe
LegalFactReview_v0.6.0-rc1_windows_installer_embedded_python.exe
LegalFactReview_v0.6.0-rc1_windows_installer.sha256.txt
```

## Python 版本要求

- 推荐 Python 3.12。
- 支持 Python 3.10-3.12。
- 不支持 Python 3.13。
- 如果只找到 Python 3.13，会提示：`未找到受支持的 Python 版本。请安装 Python 3.10-3.12，推荐 Python 3.12。`

## 隐私与边界

- 不上传文书。
- 不接入外部 API。
- 不自动连接企查查、法院系统或内部数据库。
- 不保存完整原文书正文。
- 不自动修改原文书。
- 输出不构成法律意见，不替代律师判断。

## 当前环境构建状态

当前 Codex 环境缺少 `npm/Node.js` PATH，installer 构建脚本会清晰失败并提示安装 Node.js 18+ LTS。正式推荐使用 Node.js 20/22 LTS 构建；Node 25 可尝试但不作为正式推荐。具备 Node/npm 的 Windows 构建机应继续执行 `scripts/check_installer_env.py` 和 `scripts/build_windows_installer.py`。

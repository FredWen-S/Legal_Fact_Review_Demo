# 桌面版说明

## 定位

桌面版是现有本地 Streamlit 工具的桌面壳。它负责启动、停止和查看本地 Python 服务状态，不重写复核引擎，不改变规则配置中心、案件工作区、报告导出或 SQLite 留痕逻辑。

架构：

```text
Tauri Desktop Shell
  -> scripts/desktop_service.py
  -> 本地 Python 虚拟环境
  -> Streamlit app/main.py
```

配置中心用于调整辅助复核规则，不代表系统能够自动完成法律判断。

## 开发模式启动

桌面壳使用 Tauri v2。开发环境需要：

- Node.js 18 或更高版本。
- Rust stable 和 Cargo。
- Windows WebView2 Runtime。
- Python 3.10-3.12，推荐 Python 3.11 或 3.12。

命令：

```bash
cd desktop
npm install
npm run dev
```

如果不运行 Tauri，也可以直接管理本地服务：

```bash
python scripts/desktop_service.py status
python scripts/desktop_service.py start
python scripts/desktop_service.py stop
python scripts/desktop_service.py logs
```

`start` 会检查目录完整性、创建 `data/`、`exports/`、`logs/`，创建或复用 `.venv`，安装依赖并启动 Streamlit。

## 桌面壳按钮

- 启动本地服务：启动 Python / Streamlit。
- 打开复核界面：打开 `http://localhost:<port>`。
- 停止本地服务：仅停止 `logs/service.pid` 中记录的本项目进程。
- 打开 data 目录：查看本地 SQLite 和数据文件。
- 打开 exports 目录：查看导出归档目录。
- 打开 logs 目录：查看 `desktop_service.log`、`startup.log` 等日志。

## 数据目录

桌面版沿用现有目录：

```text
data/
exports/
logs/
```

release 包不会包含用户 SQLite 数据或用户上传文件。SQLite 不保存完整上传文书正文。

## 启动失败排查

常见原因：

- Python 未安装，或版本不是 3.10-3.12。
- `app/main.py` 或 `requirements.txt` 缺失。
- 依赖安装失败。
- wheelhouse 与当前 Python 版本不匹配。
- 端口 8501-8510 均被占用。
- 服务启动超时。

请先查看：

```text
logs/desktop_service.log
logs/startup.log
```

## 与 portable 版区别

| 版本 | 启动方式 | 适合对象 |
| --- | --- | --- |
| Portable Streamlit 版 | 双击 `start.bat` | 稳定演示、低依赖交付 |
| Tauri 桌面壳版 | 打开桌面壳，再启动本地服务 | 更接近桌面应用体验 |
| 开发者模式 | `streamlit run app/main.py` / `npm run dev` | 开发调试 |

v0.5.0-rc1 桌面壳仍依赖本地 Python 服务，不是完全独立 exe。桌面壳负责启动、停止和打开本地 Streamlit 服务；核心复核功能仍由 Python / Streamlit 提供。现有 Streamlit 源码启动、Docker 启动和 Windows portable `start.bat` 都继续保留。

## 发布前检查

验收脚本应使用临时目录生成测试 case，不应修改 `app/sample_data/test_cases/`。发布前请确认该目录没有因验收脚本产生非预期 modified；如需手动恢复测试数据，可执行：

```bash
git restore -- app/sample_data/test_cases
```

## 边界

- 不接入外部 API。
- 不上传文件。
- 不访问第三方网站或外部数据库。
- 不自动修改原文书。
- 不保存完整上传文书正文到 SQLite。
- 输出结果仅用于辅助人工复核，不构成法律意见。

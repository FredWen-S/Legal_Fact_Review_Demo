# 规则配置说明

## 配置文件位置

默认规则配置文件位于：

```text
app/config/review_rules.yml
```

规则配置中心支持导出、导入和恢复默认配置。配置错误时系统会回退到内置默认配置，避免复核流程崩溃。

配置中心用于调整辅助复核规则，不代表系统能够自动完成法律判断。所有输出都应理解为“建议人工复核”的线索，最终判断由律师或相关人员完成。

## 导出配置

在 Streamlit 侧边栏进入“规则配置”，点击“导出当前规则配置”，会下载：

```text
review_rules_export_<timestamp>.yml
```

## 导入配置

支持导入 YAML 或 JSON。导入前会校验：

- 风险类型必须合法。
- severity 只能是 `low`、`medium`、`high`。
- `suggested_action` 必须包含“建议人工复核”。
- 不允许出现绝对化错误判断、法律效力判断或替代人工判断的表述。

导入成功前会自动备份旧配置：

```text
data/config_backups/review_rules_<timestamp>.yml
```

## 恢复默认

“恢复默认规则配置”需要二次确认。恢复默认不会删除案件工作区、历史复核记录、人工复核记录或导出报告。

## 文书类型模板

内置模板包括：

- 通用文书 `general`
- 民事起诉状 `civil_complaint`
- 答辩状 `defense_statement`
- 仲裁申请书 `arbitration_application`
- 合同审查 `contract_review`
- 律师函 `lawyer_letter`
- 执行申请书 `enforcement_application`

模板可配置 `required_fields`、字段别名和金额/日期/证据关键词。复核时选择文书类型模板，会影响 MISSING_FIELD 的必填字段范围。

## 字段词典

字段词典配置字段展示名、alias、正则模式、建议复核来源、默认风险等级和是否默认必填。规则配置中心支持查看字段词典、编辑 alias，并导入/导出完整配置。alias 会影响字段标签识别，例如给“法定代表人”增加“负责人”后，系统会尝试识别“负责人：张三”这类表述。

## 风险等级

风险等级支持：

- `low`
- `medium`
- `high`

不建议随意禁用高风险项，尤其是主体、金额、证据编号、占位符和外部资料不一致相关风险。禁用风险类型后，系统将不再输出该类提示。

## 配置错误处理

配置文件损坏、字段非法或建议动作不合规时，系统会回退到默认配置，并在规则配置中心显示 warning。导入失败不会覆盖旧配置。

## 配置历史

每次通过 UI 导入、保存或恢复默认配置，会写入 SQLite 表 `rule_config_history`。该表只保存配置版本、保存时间、备注、备份路径和当前配置路径，不保存上传文书内容。

每次复核会在 `review_runs` 中记录当次 `config_version` 和 `document_profile`。历史记录和重新导出的报告使用当次保存值展示，不会因为当前配置变化而覆盖历史元数据。

# Synthetic Knowledge Base

All files under `kb/clients`, `kb/clauses`, and `kb/templates` are synthetic demo data created for local testing and portfolio demonstration.

- `kb/clients`: fictional client profiles
- `kb/clauses`: fictional standard clause records
- `kb/templates`: fictional template metadata used by lightweight RAG retrieval
- `kb/statutes`: public statute metadata (name, status, effective / repeal date, article count) used to cross-check extracted statute citations. This is a small demo reference list, not a legal database; verify against official published texts.

No real client records, real contracts, or confidential legal materials are included.
